# Third-party components

- Google Fonts: DM Sans and Space Grotesk, loaded by the demo page for typography.
- `serve` is used through `npx` by the local `npm start` script.
- Python standard library `http.server`, `sqlite3`, `hashlib`, and `unittest` power the API, persistence, password hashing, and tests.
- No solver, AI provider, analytics SDK, or hosted database is used by the current prototype.
